# APIs — government & civic data

Useful public APIs for collecting or serving digital-government information.

- [data.gov API](https://api.data.gov) — search and retrieve U.S. open datasets
- [Google Civic Information API](https://developers.google.com/civic-information) — civic data (reps, polling, elections)
- [Open311](https://www.open311.org) — standard for civic issue tracking and service requests
- [Socrata Open Data API (SODA)](https://dev.socrata.com) — query city open-data portals
- [CKAN API](https://docs.ckan.org/en/latest/api/) — open-source data portal API (used by many governments)

Add more as we find them. Prefer documented, rate-limit-friendly endpoints.
