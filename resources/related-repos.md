# Related repositories

Other open-source projects doing similar work — collecting government data, building civic AI tools, or curating digital-government resources. Useful for inspiration, collaboration, or avoiding duplication.

## Closest matches (data collection + AI for government)

- [civic-ai-tools](https://github.com/npstorey/civic-ai-tools) — MCP server + curated directory connecting AI assistants to 559 Socrata open-data portals (MIT)
- [CivLib / bap](https://github.com/DILIP-SHEESH/bap) — civic intelligence platform: live government datasets → AI insights, anomaly detection, natural-language analytics (Bengaluru-focused)
- [civ.iq](https://github.com/civdotiq/civ.iq) — civic intelligence from 26+ government data sources (Congress, FEC, Census, OpenStates, etc.)
- [agentic-house-search-data-registry](https://github.com/asturksever/agentic-house-search-data-registry) — UK postcode → government open data report + MCP server (45 datasets)
- [open-govtech-report](https://github.com/AndreasThinks/open-govtech-report) — scrapes & LLM-tags every public GitHub repo belonging to government orgs worldwide
- [polis](https://github.com/compdemocracy/polis) — open-source AI for large-scale open-ended civic feedback (AGPL)
- [Hack23/cia](https://github.com/Hack23/cia) — Citizen Intelligence Agency: AI + data viz on Swedish parliamentary/government data (Apache 2.0)
