# Open-source projects — digital government & AI

Curated list of existing open-source work to learn from, build on, or avoid duplicating. Add entries with a one-line description and link.

## Civic engagement & participation

- [Your Priorities / Policy Synth](https://github.com/CitizensFoundation/your-priorities-app) — participatory democracy platform with AI agent teams for policy research (Citizens Foundation)
- [CONSUL Democracy](https://github.com/consul/consul) — citizen participation: debates, proposals, voting, participatory budgeting (250+ cities)
- [Decidim](https://github.com/decidim/decidim) — digital infrastructure for participatory democracy
- [Jigsaw Sensemaking AI](https://github.com/google/sensemaking-ai) — open-source tools for large-scale civic conversations and community input analysis

## Open data & AI tooling for cities

- [civic-ai-tools](https://github.com/npstorey/civic-ai-tools) — MCP server + curated civic MCP directory connecting AI assistants to 559 Socrata open-data portals
- [Boston open-source agentic AI skills](https://statescoop.com/bostons-cio-open-source-agentic-ai-tools/) — MCP server and agent skills for analyzing city open data (property, 311, permits, etc.)
- [CivicSunshine](https://github.com/townlight/sunshine) — locally-hosted AI for municipal open-records (FOIA) request processing
- [estonia-ai-kit](https://github.com/stefanoamorelli/estonia-ai-kit) — MCP servers and skills for Estonian government digital infrastructure
- [government-services (Israel)](https://github.com/skills-il/government-services) — AI agent skills for Israeli government APIs

## Transparency & algorithm registers

- [Algorithm Register (Amsterdam / Helsinki / Eurocities)](https://www.algorithmregister.org/) — open-source data schema for city algorithm registers
- [Great North US Federal AI Use Case Inventory](https://huggingface.co/datasets/GreatNorthCollective/greatnorth-us-federal-ai-inventory) — normalized dataset of 3,611 U.S. federal AI use cases (OMB 2025)
